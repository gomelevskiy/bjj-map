# Карта связок BJJ

PWA на русском: отмечаешь, что умеешь в бразильском джиу-джитсу, собираешь связки, ведёшь дневник тренировок, читаешь разборы приёмов и видишь пробелы в игре. Работает офлайн и ставится на телефон иконкой.

Сервера и аккаунтов нет: все данные хранятся только в браузере на устройстве. Перенос между устройствами — кодом в разделе «Профиль».

## Состав

| Путь | Что внутри |
| --- | --- |
| `web/` | Приложение: Vite + vite-plugin-pwa, без фреймворка |
| `shared/catalog.json` | Справочник: 40 позиций, 228 техник |
| `shared/howto.json` | Разборы приёмов (черновик, сверить с тренером) |
| `.github/workflows/pages.yml` | Сборка и публикация на GitHub Pages |

## Локально

```bash
cd web && npm install && npm run dev    # http://localhost:5173
```

## GitHub Pages

1. Репозиторий → Settings → Pages → Source: **GitHub Actions**.
2. Пуш в `main` собирает приложение и публикует его на `https://<логин>.github.io/<репозиторий>/`.
3. Свой домен: Settings → Pages → Custom domain, а в workflow поменяй `VITE_BASE` на `/`.

## Данные

У каждой записи (статус, связка, тренировка, заметка) есть время изменения. При загрузке кода с другого устройства записи сливаются: побеждает более свежая. Удаления хранятся как метки.
